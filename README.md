## Engineering mindset

My background in electronics and industrial engineering strongly influences how I write software.

When debugging a system, I prefer to:

1. isolate the problem,
2. collect evidence,
3. test hypotheses,
4. understand the root cause,
5. validate the final behavior.

I apply the same approach whether I am debugging a PCB, an STM32 Ethernet interface or a web API.
